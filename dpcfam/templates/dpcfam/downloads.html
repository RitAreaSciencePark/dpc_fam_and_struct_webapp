DPCfam Downloads

The archives below package the biological data for all 81,384 DPCfam metaclusters as compressed bundles (.tar.gz). If you only need the files for a specific metacluster, individual FASTA, MSA, and HMM files are available directly on each metacluster's detail page, under the Downloads tab.

DPCstruct Downloads

The archives below package the biological data for all 28,246 DPCstruct metaclusters as compressed bundles (.tar.gz). Each metacluster holds at most two representative elements: the cluster center and the domain with the highest pLDDT confidence score. When both point to the same domain, only one file is present (e.g. MC2011). If you only need the data for a specific metacluster, FASTA and PDB files are available directly from its detail page, under the Downloads tab.
